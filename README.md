# 📌 TechNews Today

## 📰 Sobre o projeto

O **TechNews Today** é um portal de notícias sobre tecnologia desenvolvido com **HTML e CSS**, como parte do Desafio 10A. O projeto apresenta um layout moderno com efeito **Glassmorphism**, título com gradiente, vídeo incorporado e formulário de newsletter.

## 🎯 Objetivo

Aplicar conceitos de **CSS3** para estilizar uma página HTML, utilizando recursos modernos de layout, cores, efeitos visuais e responsividade.

## 🛠️ Tecnologias utilizadas

HTML5
CSS3
CSS Grid
Responsividade
Glassmorphism
Gradientes
backdrop-filter
position: sticky
Media Query
